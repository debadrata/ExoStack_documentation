ExoStack / ROS 2 interfaces

Synchronizer

Matches the hub messages in time and republishes all channels as one array.

The synchronizer subscribes to every hub listed in sensors.yaml and matches their messages with an approximate-time policy (queue 5, tolerance slop_time). It starts in trigger mode, publishing /sync_trigger at 5 Hz so that every hub re-zeroes its clock; at the first matched set it switches to sync mode. If no matched set arrives for 1 s, it resets and triggers again. Repeated matches with identical stamps are dropped.
