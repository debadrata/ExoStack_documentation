ExoStack / ROS 2 interfaces

Motion planner

Plays the active profile after each gait event and publishes the actuator set-point.

At every event on gait_event_topic the planner starts its active profile. A profile that arrives while one is playing waits in a buffer and becomes active only between executions, so the assistance never changes mid-stride. At rate it publishes next_point(t) of its plug-in, with t the time since the event (time_based) or the gait phase (gait_phase_based), and default_output outside the profile window or on an emergency stop.
