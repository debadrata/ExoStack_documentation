# ExoStack documentation

Documentation website of **ExoStack**, a modular and reconfigurable software framework for wearable robotics using ROS 2:
**https://debadrata.github.io/ExoStack_documentation/**

- Source code: <https://github.com/debadrata/ExoStack>
- User manual (PDF): [ExoStack_User_Manual.pdf](ExoStack_User_Manual.pdf)

The site is static HTML, served by GitHub Pages from the root of this repository (`.nojekyll` keeps the files as they are).
